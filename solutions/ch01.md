## Chapter 1: Diagnostic Test

**D1.** O(n). Bottom-up heap construction sifts down each internal node; most nodes sit near the bottom and move only a few levels. Summing the heights, Σ n/2^{h+1} × O(h) = O(n). (Inserting the elements one by one is O(n log n).) Section 3.7.

**D2.** 6. The number of rolls is geometric with p = 1/6, so the mean is 1/p. Section 2.5.

**D3.** 1 − (5/6)^{4} = 671/1296 ≈ 0.518. Use the complement for "at least one". Section 2.2.

**D4.** 12. `a` sits at offset 0; `b` needs 4-byte alignment, so 3 padding bytes follow `a` and `b` occupies offsets 4–7; `c` is at offset 8; 3 bytes of tail padding make the size a multiple of the struct's alignment (4), so arrays of S keep every `b` aligned. Reordering the members as `int b; char a; char c;` gives 8. Chapter 6.

**D5.** The vector must reallocate: it allocates a larger buffer, moves or copies the elements, and frees the old buffer. *All* iterators, pointers and references to elements are invalidated. Chapter 10.

**D6.** No. Signed overflow is undefined behaviour, and optimizers rely on that (for example, assuming `i + 1 > i`). Unsigned arithmetic, by contrast, is defined to wrap modulo 2^{n}. Chapter 11.

**D7.** Nothing at runtime. `std::move` is a cast to an rvalue reference (`static_cast<T&&>`); it only makes the move constructor or move assignment eligible for overload resolution. Whether anything is moved depends on what receives the result. Chapter 8.

**D8.** 64 bytes. Chapter 12.

**D9.** UDP multicast. The network replicates one packet to every subscriber, so the sender's cost does not grow with the number of subscribers, and there is no per-receiver connection state, retransmission or head-of-line blocking delaying everyone else. Receivers detect lost packets through sequence numbers and recover through separate channels. Chapter 15.

**D10.** An acquire load on the same atomic variable that reads the value written by the release store. Together they create a *happens-before* relationship: every write the storing thread made before the release is visible to the loading thread after the acquire. Chapter 14.
